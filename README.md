# multiplication-table

Two small Python scripts that print a multiplication table for a number entered by the user.

## Files

- `multiplication_table.py` — prints `n x i = result` for `i` from 1 to 10.
- `multiplication_table_v2.py` — a shorter version using `range()` with a step, printing just the results.

## Running

```bash
python3 multiplication_table.py
python3 multiplication_table_v2.py
```
